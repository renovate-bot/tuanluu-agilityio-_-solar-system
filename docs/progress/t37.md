## Summary

- `SUPPORTED_LANGS = ['vi', 'en', 'ja']` in `src/data/types.ts`, and `Lang` is derived from it. `detectLang` picks the first browser language whose primary subtag is supported (case-insensitive, so `ja-JP` gives `ja`) and otherwise falls back to `en`. A valid saved `sse.lang` always wins. Numbers are formatted with `ja-JP`.
- Japanese UI table (`src/i18n/strings.ts`), body content (`src/data/content/ja.ts`) and 14 tour scripts (`src/data/tour/ja.json`). All are AI-translated from the English source and **not proofread by a native speaker**.
- Narration fallback is now language-aware. Duration counts words with `Intl.Segmenter`, falling back when the API is missing. Sentences split on `。！？`, and a `.` between digits counts as a decimal point. The TS code and the Python generator do the same thing.
- The Edge TTS generator gained the voice `ja-JP-NanamiNeural`. It generated 14 Japanese MP3s, and the manifest now has 42 stop/language segments; vi/en audio and cues are unchanged. A new `align_cue_text()` puts back source punctuation that Edge TTS rewrote in the cue text (`・` came back as `、`).
- `src/ui/languagePicker.ts` is an accessible modal with three native-name options. It marks the current language with `aria-current`, traps Tab focus, and closes on a choice, the close button, Escape or a backdrop click; focus then returns to the opener. It is a bottom sheet on mobile (with safe areas) and a centred dialog on desktop. The `文A` opener replaces the vi/en toggle. The selection, panel and tour state are kept, and changing the language mid-stop replays that stop in the new language.
- AGENTS.md and `src/data/CLAUDE.md` now describe the three locales, the detection rule, the voices, English as the canonical source, and that the Japanese is not proofread.
