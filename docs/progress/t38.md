## Decisions

- DECISION: Task number 38 (33 to 37 are taken), branch `feat/t38-german-support`.
- DECISION: The voice is `de-DE-KatjaNeural` (female, like HoaiMy, Ava and Nanami), confirmed with `edge_tts.list_voices()`.
- DECISION: German uses the informal "du".
- DECISION: German tour scripts must be 45 to 105 words (`[45, 105]`), because German runs longer than English.
- DECISION: Scripts avoid a mid-sentence dot (such as a number followed by a dot, or abbreviations) and a guard test enforces it, instead of changing the sentence splitter, so the vi/en/ja cues stay unchanged.
- DECISION: The prefs tests used `de` as the unsupported sample language; it is now `fr`.
- DECISION: The label check in the fit test asserts the label rectangle stays inside the viewport (labels are nowrap auto-width buttons inside an overflow-hidden layer); a `scrollWidth` test gave false positives on short names.
